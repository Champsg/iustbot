# Technology Stack

## Core
- **Node.js**: Runtime environment for both server and build tools.
- **React 19**: Frontend library for building the user interface.
- **Vite 8**: Frontend build tool and development server.
- **Express 5**: Web framework for the backend API and serving the frontend.

## Database & Authentication
- **Supabase**: Backend-as-a-Service providing PostgreSQL database and client-side integration.
- **@supabase/supabase-js**: Client library for database interactions.

## Automation & Scraping
- **node-cron**: Task scheduler for periodic scraping.
- **cheerio**: Fast, flexible, and lean implementation of core jQuery for scraping.
- **axios**: Promise-based HTTP client for fetching data from the IUST website and self-pinging.

## Telegram Bot
- **Telegraf**: Modern Telegram Bot Framework for Node.js.

## UI/UX
- **framer-motion**: Animation library for React.
- **lucide-react**: Icon set for React.
- **Vanilla CSS**: Used for styling with modern variables and glassmorphism.

## Utilities
- **dotenv**: Loads environment variables from a `.env` file.
- **cors**: Middleware for enabling Cross-Origin Resource Sharing.
- **concurrently**: Tool to run multiple commands simultaneously (dev server + backend server).
- **nodemon**: Monitor for changes in node.js applications and automatically restart the server.
